# Code of Conduct

NekoDroid is intended to be a welcoming, practical open-source project.

## Expected behaviour

Be respectful, constructive, and patient. Discuss ideas and code rather than attacking people. Respect names, pronouns, identities, accessibility needs, experience levels, and cultural differences. Give actionable technical feedback and assume good faith where reasonable.

## Unacceptable behaviour

Harassment, threats, hate speech, sexual harassment, doxxing, stalking, deliberate intimidation, discriminatory slurs, repeated personal attacks, or publishing another person's private information are not acceptable.

## Project spaces

These expectations apply to repository discussions, issues, pull requests, code review, project chat, and other spaces representing NekoDroid.

## Enforcement

Maintainers may edit or remove abusive content, close discussions, restrict participation, or ban contributors when needed to protect the community. Serious safety concerns should be reported privately to the project owner rather than escalated publicly.

## Scope

Technical disagreement is welcome. Critique the implementation, evidence, or proposal without degrading the person behind it.
